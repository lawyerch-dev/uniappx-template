# 正式项目上线检查清单

本工程基于官方 `hello-uniapp-x` 演示工程改造而来，仍保留大量演示专用内容。
正式项目上线前，请按本清单逐项处理。

## 一、占位资源（必须替换）

| 位置 | 内容 | 处理 |
|---|---|---|
| `package/` | 应用图标（`icon1024.png` `icon144.png` `icon192.png` `icon256.png` `D-1024.png` `background*.png` 等） | 换成你自己的应用图标 |
| `harmony-configs/config/` | 鸿蒙签名证书（`hello-uni-app-x.p12` `.p7b` `.csr` `.cer`） | 换成你自己的签名证书 |
| `static/` | 演示配图（`componentIndex.png` `apiIndex.png` `cssIndex.png` `extuiIndex.png` `templateIndex.png` 等） | 删示例后可一并清理 |
| `nativeResources/` | iOS entitlements / Android res | 按需确认 |

## 二、应用标识（当前为占位值，需替换）

| 文件 | 字段 | 当前占位值 |
|---|---|---|
| `manifest.json` | `name` | `my-app` |
| `manifest.json` | `app-harmony.distribute.bundleName` | `com.example.myapp` |
| `manifest.json` | `versionName` / `versionCode` | `1.0.0` / `100` |
| `package.json` | `id` / `name` / `displayName` / `version` | `my-app` / `1.0.0` |
| `pages.json` | `globalStyle.navigationBarTitleText` | `my-app` |

## 三、manifest.json 演示配置（按需清理，当前未动）

| 字段 | 说明 |
|---|---|
| `app.distribute.modules.uni-ad` | 广告模块，不用广告可删 |
| `app-harmony` / `app-android` / `app-ios`.distribute.modules | `uni-location` / `uni-map` / `uni-payment` / `uni-push` / `uni-oauth` / `uni-share` / `uni-barcode-scanning` 等，按实际用到的保留 |
| 各平台 oauth/share 的微信 `appid` | 已清空，填你自己的 |
| `mp-weixin.requiredPrivateInfos` / `permission` | 定位相关，不用可删 |
| 各平台 `icons` / `splashScreens` | 引用 `package/` 占位图标 |

## 四、代码里的演示逻辑（按注释清理）

代码中已用 `[演示专用]` / `[示例]` 标注，正式项目按注释删除：

| 文件 | 标注内容 |
|---|---|
| `App.uvue` | 自动化测试计数、uni 统计上报、scheme/ulink 直达、隐私弹窗、全局样式测试 |
| `main.uts` | `uniStat` 统计引入与 `app.use` |
| `store/index.uts` | `globalData` / `lifeCycleNum` / `eventCallbackNum` / PC 分栏与示例 tab 字段 |

## 五、示例与演示依赖（长期保留则无需处理）

| 位置 | 说明 |
|---|---|
| `examples/` | 官方示例（6 个分包），长期作参考 |
| `uni_modules/test-*` `uts-*` | 示例专用插件 |
| `wxcomponents/vant` | vant 小程序示例专用 |
| `uniCloud-alipay/` | 示例用云函数 |
| `windows/` + `pages.json` 的 `leftWindow`/`topWindow` | PC 分栏演示 |

> 若以后决定删除 `examples/`，可同步清理上表内容，并把 `pages.json` 的 `groups` 菜单树一并删除
> （`groups` 仅被示例目录页的 `examples/tabBar/generateMenu.uts` 依赖）。
